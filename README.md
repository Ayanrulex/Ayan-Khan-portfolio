# Ayan Khan — Web Developer Portfolio

A responsive, recruiter-focused personal portfolio built with HTML, CSS and JavaScript.

## Highlights
- Animated, responsive single-page layout
- Featured Extroverts project with live Vercel demo and GitHub source
- Skills, projects, experience and education sections
- Mobile navigation and scroll-reveal effects
- No build step or framework required for the portfolio itself

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository used for `ayanrulex.github.io`, then enable GitHub Pages from the `main` branch and root folder.
